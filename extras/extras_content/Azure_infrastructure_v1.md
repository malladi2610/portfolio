# My experieces
1. This is a cloud template project that was created for the classification task
2. This is for a freelance project where the requirement was to classify the data in the source URL using the data in the reference website
3. It was a really intresting project for me as this the first time I created a complete end-end templaate that has a frontend, n8n workflow and postgres database all connected together
4. THis is also the first project I learnt about the IaC and deploayed the entire project in azure using Terraform and was really surpreised how well it worked
5. This project taught me how to map out the entire workflow before the actual work begin, then do a local implementation, test everything thoroughly and then go ahead with the cloud deployment
6. This project is actually a step ahead to my n8n_pipeline project which was just the workflow with no end-end itegrations and this project, I took a lot of first steps and made this working template.
7. This is a cloud agnostic template that works irrespective of which cloud service is used
8. Overall, it was a great learning experience, where I learnt about docker, n8n workflow, postgres SQL database, Terrafrom and Azure cloud implementation.
