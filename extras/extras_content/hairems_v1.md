# My experiences
1. This project started with the vision to learn the concept of Edge AI and also give a submission for the mini-project submission
2. This was a project where I integrated multiple sensors and microcontrollers and all had to come together and functions correctly
3. It was supposed to address the problems faced in the ICU due to the shortage of the hospital staff, who were already being over worked.
4. It was developed during COVID period and was developed keeping in mind the situations back then which are continuous oxygen level monitoring of the cylinders, patient movement detection using edge AI and also the patient saline level detection
5. It had multiple microcontrollers which are two nodemcu which were to collect the data from the saline bottle, and oxygen cylinder and to detect the patient movement(Which is patient state detection), this is done by the analysing the sounds created within the ICU machines and using them to classify the state
6. All these data from multiple microcontroller and collected from multiple sensors is sent to a single cloud which was adafruit and then utilise them to take the action
7. There are threshold set to all these datapoints in the cloud logic and would trigger a notification to the concerned personnel when the data goes below the threshold point and all this data is available in the mobile applicattion too.
8. Due to the covid the main challenge faced to test on the real system like the actual saline bottle, oxygen cylinder and actual ICU environment
9. overall, It was one of the completely integrated project that I developed where multiple systems came together to address one major problem being faced in the hospitals even today. which makes this project special by having relevance even after 4 years.
