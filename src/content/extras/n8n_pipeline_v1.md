# My experiences

1. This project was started to solve the problem I was facing: I was overwhelmed by the number of LinkedIn job recommendations for different jobs, and I needed a way to automate the process to get the final list of companies I could apply to based on my profile.
2. This application is also my first step towards learning automation and integrating multiple services using the n8n pipeline.
3. What started as a simple extraction of the Job recommendation from email only for LinkedIn, extended to Glassdoor and Indeed.
4. It also introduced me to how different datapoints needs to be collected, cleaned, and organised to be given to an AI model for performing the classification on whether this Job is for me or not.
5. THe amount of Jobs that got filtered during the initial run from around 10-15 emails that I get from LinkedIn, Indeed, Glassdoor showed me that there are a lot opportunites available, and if the timing is right, then we can find the job easily
6. This entire piple which starts executing by taking a date input, reads all the emails which have been sent to me which in my case are around 10-15 emails runs for around 30 -40 mins and gives me the final list of cJob opportunies that I need to apply in notions which are perfect fit to my CV and profile, this automates the entire process of the JOb serach part of the entire three part process of Getting the Job which are : Job search part, Job prepapration and Applying to the JOb.
7. This project taught me n8n, using openAI api and doing cost optimisations, and also integrating with different third-party services like Gmail, notion and services to extract the Job description from LinkedIn, Indeed, Glassdoor, etc…
8. Though I have used the n8n cloud hosting service to host the pipeline once I build it, local hosting of the pipeline and automatically running it periodically using the schedules would be a much more beneficial next step for this project
9. Overall, it was a fun project that addressed my needs and prepared me for current market demands, where everyone is looking for engineers experienced in building automation pipelines, utilising AI models effectively, and developing use cases around them.
